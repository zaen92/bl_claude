# 개인정보·데이터 처리 메모 (개인정보 처리방침 작성용 기초 자료)

> 법률 검토를 거친 문서가 아닙니다. 실제 처리방침은 이 내용을 바탕으로 별도 작성·검토하세요.

## 저장하는 정보
| 위치 | 내용 | 보관 |
|---|---|---|
| Firebase Authentication | 이메일, (Google 로그인 시) 이름·프로필 사진 URL, 인증 여부 | 탈퇴 시 삭제 |
| `users/{uid}` | 표시 이름, 이메일, 회원 등급(FREE/PRO), 크레딧 잔액, 사용량(내보내기 횟수·저장 글 수·스타일 수), 가입·로그인 시각 | 탈퇴 시 삭제 |
| `creditLedger` | 크레딧 증감 내역 (금액·사유·시각) | 회계 목적 보관 (탈퇴 후에도 uid 만 남음 — 정책 확정 필요) |
| `generations` | 생성 입력 **텍스트**(제목·메모·내용·장소 정보)·생성 결과·작성 스타일 스냅샷, 사진 장수 | 탈퇴 시 삭제 |
| `posts` | 사용자가 저장한 글 (텍스트만) | 탈퇴 또는 삭제 시 |
| `styles` | 개인화 작성 스타일 (블로그 이름·인사말·마무리·문체·추가 지침) | 탈퇴 또는 삭제 시 |
| `exportGrants` | JSON 내보내기 승인 기록 (uid·시각, 파일 내용 없음) | 탈퇴 시 삭제 |
| `generationMetrics` / `opsDaily` | 토큰·비용·지연 시간 등 운영 지표 (입력 내용·이메일 없음) | 회계 목적 보관 |
| `signupGrants` | 정규화 이메일의 **SHA-256 해시** (재가입 보너스 중복 방지, 이메일 원문 없음) | 탈퇴 후에도 보관 (목적: 무료 크레딧 악용 방지) |

## 저장하지 않는 정보
- **사진**: 브라우저 메모리에서 압축 후 생성 요청과 함께 Claude API 로 전달되어 분석에만 쓰이고, Firestore·Cloud Storage·로그 어디에도 저장하지 않습니다. 새로고침하면 사라집니다.
- API 키: 사용자는 입력하지 않으며, 운영자 키는 Secret Manager 에만 있습니다.
- JSON 내보내기 파일: 사용자의 기기에만 저장됩니다. 서버는 승인 횟수만 기록합니다.

## 외부 전송 (제3자 처리)
- **Anthropic (Claude API)**: 생성 요청 시 입력 텍스트·사진·작성 스타일을 전송 (결과 생성 목적). Anthropic 의 데이터 처리 정책 확인·고지 필요
- **네이버 지역검색 API** (설정한 경우): 글 제목(최대 100자), 결과가 없으면 내용의 첫 문장만 검색어로 전송
- **Google (Firebase)**: 인증·데이터베이스·서버 실행 인프라

## 브라우저 저장 (localStorage)
- 생성 진행 중 요청 ID(새로고침 후 이어받기용), 선택한 작성 스타일, 예전 버전이 남긴 저장 글(계정으로 가져온 뒤에도 백업으로 그대로 남김)
- 예전 버전이 저장했던 API 키 항목은 앱이 열릴 때 자동 삭제합니다.

## 회원 탈퇴
`deleteAccount` → 저장 글·생성 기록·스타일·내보내기 승인 기록·회원 문서·Auth 계정 삭제 (최근 10분 내 로그인 필요). 크레딧은 소멸합니다.
